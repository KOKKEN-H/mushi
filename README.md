# 蟲神器ソロバトル（プロトタイプ）

ダイソーの昆虫対戦TCG「蟲神器」を1人で遊べるようにしたブラウザゲームです。

## 遊び方

`index.html` をブラウザで開くだけです。ビルドや依存パッケージのインストールは
不要です（見出し等のフォント表示にGoogle Fontsを使っているため、初回はネット
接続があると見た目が最適です。オフラインでもフォールバックフォントで動作します）。

1. デッキ編成画面で20枚ちょうどのデッキを組む（🎲ランダム構築も使えます）
2. 「次へ（相手を選ぶ）」でCPUのデッキタイプ（アグロ／ミッドレンジ／コントロール／
   単色特化／ランダム）を選ぶ
3. 対戦開始

## 収録カード

- スターターセット：全24種
- ブースターパック第1弾：全79種
- ブースターパック第2弾：全55種
- 合計158種

コスト・体力・攻撃力・色・レアリティは公式データベース準拠。技の個別効果は、
共通ルールとして定義されているキーワード技のみ実際の効果を再現しています。
詳しくは `CLAUDE.md` を参照してください。

## 開発者向け

このプロジェクトを Claude Code で開く場合、まず `CLAUDE.md` を読んでください。
現在の実装状況・アーキテクチャ・既知の制約・今後の課題がまとまっています。

簡易な動作確認は `tests/headless-sim.js` を Node.js で実行することでできます
（`node tests/headless-sim.js [回数]`）。ランダムなデッキ同士でCPU対CPUの対戦を
自動で複数回行い、例外が発生しないかを確認します。
